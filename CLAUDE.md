# Instructions for Claude Code in This Repository

Before doing anything else in this project, read `PROJECT_HANDOFF.md` in full. It contains the settled decisions that should not be re-derived, the current state of the work, a full file index, and the active punch list.

After making any meaningful change in this repo (a decision gets finalized, a file gets created, restructured, or resolved, an open item from `Edit_Notes_From_Sarene.md` gets addressed), add a dated entry to the Changelog section at the bottom of `PROJECT_HANDOFF.md`. Keep entries short, one or two lines.

If a "Critical Fact" listed in `PROJECT_HANDOFF.md` changes, update that section directly rather than leaving it stale or adding a contradicting note elsewhere.

House style for all written content in this repo: no em dashes, ever. Use commas, periods, or colons instead.
